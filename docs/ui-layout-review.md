# Flow 설정 화면 정렬 검토

2026년 9월 7일, 1.2.2 소스 기준의 정렬 개선을 검증했습니다. 기준 커밋은 `bcd0660`이며 아래 결과는 그 위에 적용한 작업 변경 사항에 대한 것입니다. 이번 검토에서 배포 버전 변경, 서명, 공증 또는 설치는 수행하지 않았습니다.

## 기준과 변경

같은 창에서 설정 페이지를 전환해도 제목, 설명, 본문과 첫 카드의 시작점 및 사이드바 버튼과 아이콘 위치가 움직이지 않아야 합니다. 한국어와 영어, 밝은 화면과 어두운 화면에도 같은 기준을 적용합니다.

이전에는 설명이 없는 일반과 입력 장치 페이지의 헤더가 짧았고, 첫 그룹 제목이 있는 입력 장치와 Dock 페이지의 카드가 더 아래에서 시작했습니다. 헤더는 제목 28pt, 간격 4pt, 설명 18pt로 고정했습니다. 첫 그룹은 제목이 없어도 동일한 16pt 제목 영역과 8pt 간격을 유지합니다. 비어 있는 설명과 제목 영역은 접근성 요소로 노출하지 않습니다.

## 화면 목록과 실제 좌표

좌표는 창의 콘텐츠 영역 왼쪽 위를 원점으로 한 AppKit 포인트입니다. 텍스트 필드 프레임에는 내부 여백이 포함되므로 제목 필드의 x는 199pt, 실제 글자와 카드의 왼쪽 정렬선은 201pt입니다.

| 페이지 | 설명 영역 | 첫 그룹 제목 | 제목 위쪽 y | 본문 위쪽 y | 첫 카드 위쪽 y |
| --- | --- | --- | --- | --- | --- |
| 일반 | 빈 영역 유지 | 빈 영역 유지 | 26 | 100 | 124 |
| 앱 단축키 | 앱 열기와 숨기기 안내 | 빈 영역 유지 | 26 | 100 | 124 |
| 입력 장치 | 빈 영역 유지 | 마우스 | 26 | 100 | 124 |
| 스크린샷 | 클립보드와 파일 단축키 안내 | 빈 영역 유지 | 26 | 100 | 124 |
| 잠자기 | 덮개를 닫은 상태의 동작 안내 | 빈 영역 유지 | 26 | 100 | 124 |
| Dock | 위치와 반응 설정 안내 | 위치 | 26 | 100 | 124 |

공통 설명 프레임의 y는 58pt, 제목 기준선은 47pt, 설명 기준선은 70pt입니다. 본문과 첫 카드의 x는 모두 201pt입니다. 사이드바 버튼은 x=12pt이며 위에서부터 y=94, 132, 204, 242, 314, 352pt를 유지합니다. 각 아이콘의 중심 좌표도 페이지 선택과 언어 변경 사이에 달라지지 않았습니다.

## 실행 결과

환경은 Apple Silicon, macOS 26.5, Swift 6.3.3입니다. 실제 설정 뷰에 예시 앱과 장치만 넣어 창을 표시하지 않고 그렸습니다.

| 검사 | 실행 범위 | 결과 |
| --- | --- | --- |
| 소스 빌드 | `LazyestFlow` 디버그 제품 | 통과 |
| 실제 화면 렌더링 | 6페이지 × 2언어 × 2테마 × 2폭 = 48장 | 통과 |
| 페이지 간 정렬 | 각 화면의 좌표와 기준선 34개, 허용 차이 0.5pt | 모두 일치 |
| 언어 간 정렬 | 같은 페이지, 테마, 폭의 한국어와 영어 좌표 비교 | 모두 일치 |
| 창 폭 검증 | 요청 폭, NSWindow 프레임의 콘텐츠 폭, 렌더링 폭 비교 | 860pt와 997pt 일치 |
| 화면 시각 검토 | 모든 페이지를 포함한 14장, 양 언어와 테마 및 두 폭 표본 | 잘림과 겹침 발견 없음 |
| 단축키 편집 취소 | 예시 데이터에서 페이지 전환과 취소 경로 직접 호출 | 기존 단축키 유지 |

처음에는 1060pt 렌더링을 요청했지만 이 검증 환경에서 네이티브 창과 이미지의 실제 폭은 997pt였습니다. 이후 실제로 적용되는 860pt와 997pt를 사용하고 요청 폭과 실제 폭이 다르면 실패하도록 했습니다. 이 관찰을 모든 Mac에서의 최대 창 폭으로 해석하지 않습니다.

## 재현

저장소 루트에서 아래 명령을 순서대로 실행합니다. 각 언어 폴더에 24장의 PNG와 `page-layout.json`이 생성됩니다. 실제 장치 상태, 개인 경로와 계정 정보는 사용하지 않습니다.

```sh
swift build --product LazyestFlow
.build/debug/LazyestFlow --render-previews .build/ui-layout/ko ko
.build/debug/LazyestFlow --render-previews .build/ui-layout/en en
```

성공 시 각 실행은 `LAZYEST_FLOW_PREVIEWS_OK`를 출력합니다. 페이지 간 위치 변경, 필요한 기준 뷰 누락, 가로 영역 이탈 또는 실제 창 폭 불일치는 렌더링을 실패시킵니다. 예시 모드의 단축키 편집 검증은 로컬 이벤트 모니터를 설치하지 않습니다.

## 이번 검토에서 실행하지 않은 동작

실제 키보드 입력과 마우스 스크롤, 화면 캡처, 클립보드 읽기와 쓰기, 덮개 닫기, 잠자기 방지, 화면 잠금, 관리자 권한 승인과 보조 도구 설치는 실행하지 않았습니다. 실제 사용자 설정 변경, 앱 설치와 교체, 외부 메시지 전송도 하지 않았습니다. 렌더링과 좌표 검사는 이 동작들의 정상 실행을 증명하지 않습니다.

스크롤한 페이지에서의 탐색, VoiceOver와 실제 키보드 포커스 이동, 다중 모니터에서의 창 이동은 이번 검토 범위에 포함하지 않았습니다. 공개 배포물의 서명과 공증 및 설치 검증도 별도 단계입니다.
